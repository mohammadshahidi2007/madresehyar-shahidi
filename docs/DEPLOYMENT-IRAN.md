# راهبرد میزبانی مدرسه‌یار شهیدی در ایران

## تصمیم فعلی

- کشور محل فعالیت مدرسه: ایران.
- محل مطلوب داده‌های آموزشی: داخل ایران، تا زمان بررسی حقوقی و سیاست حریم خصوصی.
- محیط توسعه و CI: بدون هزینه با GitHub Actions برای مخزن عمومی، همراه با داده‌های ساختگی.
- انتشار نسخه فعلی استاتیک: GitHub Pages؛ این سرویس جایگزین بک‌اند یا پایگاه داده نیست.
- بک‌اند و پایگاه داده عملیاتی: هنوز ارائه‌دهنده دائمیِ رایگان و واجد شرایطی تأیید نشده است.

## محدودیت ارائه‌دهندگان خارجی

Render در شرایط استفاده فعلی خود استفاده از سرویس را برای اشخاصی که در ایران مستقر یا مقیم هستند ممنوع کرده است. بنابراین Render برای این پروژه انتخاب نمی‌شود و نباید محدودیت جغرافیایی ارائه‌دهنده دور زده شود.

## گزینه‌های بدون هزینه زیرساخت ابری

برای توسعه، آزمون و نمایش از داده‌های ساختگی استفاده شود. برای اجرای آزمایشیِ بک‌اند بدون هزینه اجاره سرور می‌توان از رایانه یا سرورِ تحت مالکیت مدرسه استفاده کرد؛ مشروط به اینکه:
- دستگاه در زمان نیاز روشن و به‌روز باشد؛
- اتصال اینترنت پایدار و روش دسترسی امن فراهم باشد؛
- سرویس پایگاه داده از اینترنت عمومی قابل دسترسی مستقیم نباشد؛
- دسترسی راه دور از طریق VPN یا تونل امن و با احراز هویت قوی انجام شود؛
- نسخه پشتیبان رمزگذاری‌شده به دستگاه یا محل جداگانه ذخیره و بازیابی آن آزمایش شود.

این روش «بدون هزینه اجاره ابری» است، نه بدون هزینه مطلق؛ برق، اینترنت، نگهداری و پشتیبانی همچنان لازم‌اند. برای استفاده واقعی مدرسه، رایانه شخصیِ بدون پشتیبانی و اتصال پایدار، زیرساخت قابل اتکا محسوب نمی‌شود.

## اعتبار آزمایشی لیارا

صفحه قیمت‌گذاری لیارا اعتبار هدیه آغازین و منابع ساعتی/ماهانه پولی را نمایش می‌دهد. اعتبار هدیه، پلن رایگان دائمی نیست. هیچ منبعی تا زمان تأیید کاربر و بررسی سقف مصرف، فعال یا ارتقا داده نمی‌شود.

## دروازه‌های لازم پیش از داده واقعی

1. تأیید ارائه‌دهنده و محل فیزیکی دیتاسنتر در ایران.
2. بررسی قرارداد پردازش داده، دسترسی پشتیبانی و شرایط خروج/حذف داده.
3. تعیین مسئول نگهداری و پاسخ به رخداد.
4. فعال‌سازی HTTPS، مدیریت امن اسرار، اصل حداقل دسترسی و ثبت رخدادهای ممیزی.
5. پشتیبان‌گیری رمزگذاری‌شده و آزمون عملی بازیابی.
6. آزمون امنیتی و پذیرش کتبی مدرسه پیش از ورود اطلاعات دانش‌آموزان.

تا تحقق این موارد، از داده‌های واقعی دانش‌آموزان در محیط آزمایشی استفاده نشود.
