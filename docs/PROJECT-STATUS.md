## هدف

ساخت سامانه مدیریت آموزشی فارسی و راست‌چین برای پایه‌های هفتم تا نهم، با حفظ نسخه فعلی تا زمان تأیید جایگزین. معماری هدف Laravel، PostgreSQL و API با کنترل دسترسی سمت سرور است.

## وضعیت تأییدشده

- نسخه استاتیک فعلی و قابلیت‌های مرورگری آن در شاخه `main` حفظ شده است.
- مستندات معماری و نقشه راه در `docs/ARCHITECTURE.md` و `docs/ROADMAP.md` قرار دارند.
- اسکلت Laravel و endpoint سلامت در شاخه آزمایشی قرار دارند.
- CI برای commit `e7afb68e888e0ffb4df01570087e8295c25539b9` با نتیجه موفق ثبت شده است؛ این نتیجه فقط bootstrap و endpoint سلامت همان commit را تأیید می‌کند.
- migration اولیه و سه آزمون پایگاه داده برای سال تحصیلی، کلاس، دانش‌آموز، درس و ثبت‌نام اضافه شده‌اند.
- اجرای CI برای commit `5f8fabfb0e353d1955e6c1bf115b60a049080145` موفق بود، اما PHPUnit چهار warning درباره نبود فایل `.env` گزارش کرد؛ بنابراین این اجرا موفقِ بدون هشدار محسوب نمی‌شود.
- workflow اصلاح شده تا فایل محیط آزمایش را بسازد و کلید موقت تولید کند؛ همچنین job جداگانه PostgreSQL 16 به CI اضافه شده است.
- در CI شماره ۵۴، job مربوط به SQLite موفق شد. job PostgreSQL 16 به دلیل تنظیم `DB_SSLMODE=require` در فایل نمونه محیط با سرویس محلی بدون TLS اتصال نگرفت.
- این خطا مشخص و در `backend/phpunit.pgsql.xml` اصلاح شد: TLS فقط برای سرویس محلی CI غیرفعال شده است؛ تنظیم TLS برای محیط عملیاتی تغییر نکرده است. اجرای مجدد این اصلاح هنوز باید تأیید شود.
