## هدف

ساخت سامانه مدیریت آموزشی فارسی و راست‌چین برای پایه‌های هفتم تا نهم، با حفظ نسخه فعلی تا زمان تأیید جایگزین. معماری هدف Laravel، PostgreSQL و API با کنترل دسترسی سمت سرور است.

## وضعیت تأییدشده

- نسخه استاتیک فعلی و قابلیت‌های مرورگری آن در شاخه `main` حفظ شده است.
- مستندات معماری و نقشه راه در `docs/ARCHITECTURE.md` و `docs/ROADMAP.md` قرار دارند.
- اسکلت Laravel، endpoint سلامت و CI بک‌اند در شاخه آزمایشی اضافه شده‌اند.
- اجرای CI برای commit `e7afb68e888e0ffb4df01570087e8295c25539b9` با نتیجه موفق ثبت شده است. این نتیجه فقط bootstrap و endpoint سلامت همان commit را تأیید می‌کند.
- migration اولیه و آزمون‌های پایگاه داده برای سال تحصیلی، کلاس، دانش‌آموز، درس و ثبت‌نام در تاریخ ۱۵ نوامبر ۲۰۲۶ به شاخه آزمایشی افزوده شده‌اند.
- اجرای CI برای commitهای جدید migration/test باید جداگانه بررسی شود؛ تا پیش از نتیجه موفق، migrationها تأییدشده محسوب نمی‌شوند.

## مواردی که هنوز انجام نشده‌اند

1. تأیید اجرای migration و آزمون‌های آن روی CI در آخرین commit.
2. اجرای آزمون سازگاری واقعی با PostgreSQL؛ SQLite جایگزین این آزمون نیست.
3. تکمیل مدل‌های دامنه و قواعد اعتبارسنجی پایه ۷ تا ۹ و بازه تاریخ سال تحصیلی.
4. احراز هویت، نقش‌ها و سیاست‌های مجوز سمت سرور.
5. حضور و غیاب، ارزشیابی، نمرات و تکالیف.
6. تصمیم نهایی درباره میزبانی واجد شرایط در ایران، پشتیبان‌گیری و بازیابی.
7. بررسی امنیتی و پذیرش پیش از ورود داده واقعی.

## قواعد ثابت

- PR شماره ۵ تا عبور از آزمون‌ها و بازبینی، Draft باقی می‌ماند و ادغام نمی‌شود.
