# مدرسه‌یار شهیدی

سامانه مدیریت آموزشی پایه‌های هفتم تا نهم.

## وضعیت فعلی

نسخه آنلاین فعلی یک نمونه اولیه استاتیک است. داده‌های آن در حافظه مرورگر (localStorage) نگهداری می‌شوند و هنوز حساب کاربری، همگام‌سازی یا پایگاه داده مرکزی ندارد. تا پیش از تکمیل کنترل‌های امنیتی و انتشار نسخه عملیاتی، اطلاعات واقعی و حساس دانش‌آموزان را در آن ثبت نکنید.

## طراحی نسخه حرفه‌ای

- [معماری فنی و مدل داده اولیه](docs/ARCHITECTURE.md)
- [نقشه راه اجرایی و معیارهای پذیرش](docs/ROADMAP.md)

تصمیم اولیه معماری: حفظ نسخه فعلی و توسعه تدریجی، با Backend مبتنی بر Laravel، پایگاه داده PostgreSQL و میزبانی ابری. این موارد طرح هدف هستند و هنوز در نسخه آنلاین پیاده‌سازی نشده‌اند.
